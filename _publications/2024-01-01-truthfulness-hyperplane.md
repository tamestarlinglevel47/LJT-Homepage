On the Universal Truthfulness Hyperplane Inside LLMs, published at EMNLP 2024, First author Junteng Liu. This work discovers the universal truthfulness hyperplane inside large language models that controls the truthfulness of model outputs, with open source GitHub code repository (Universal_Truthfulness_Hyperplane) available.
